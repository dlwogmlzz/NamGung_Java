# 변수의 초기화
  ╰`지역변수`는 반드시 초기화해야(`iv, ②그 다음 초기화됨`, `cv, ①제일 먼저 초기화됨`는 `자동 초기화`, `lv`는 `수동 초기화`)
  
자동(기본은 0으로 초기화, 참조변수는 null)
    ↓
간단(=로 초기화)
    ↓
복잡({}, 생성자로 초기화)

class InitTest {
    // iv
    int x;          // 인스턴스 변수. 자동 초기화. 타입 추론(var)불가
    int y = x;      // 인스턴스 변수. 자동 초기화. 타입 추론(var)불가
    void method1() {
        int i;      // 지역 변수. `수동 초기화 필요!!`.
        int j = i;  // 에러. 지역 변수를 초기화하지 않고 사용. 수동초기화 해야 넣을 수 있다.
    }
}

* 멤버변수의 초기화
  ╰`멤버변수(iv, cv)`는 `자동 초기화` 된다.

   // 간단 초기화
   1. 명시적 초기화(explicit initialization), =대입연산자

   // 복잡 초기화
   2. 생성자(constructor)
   3. {}초기화 블럭(initialization block)
   - 인스턴스 iv초기화 블럭 : 인스턴스 변수를 초기화 하는데 사용
   - 클래스 cv초기화 블럭  : 클래스 변수를 초기화 하는데 사용

   * 명시적 초기화(explicit initialization)
   ╰`간단(=)`한 초기화. 가장 우선적으로 고려
   
    class Car {
      int door = 4;               // 기본형(primitive type) 변수의 초기화
      Engine e = new Engine();    // 참조형(reference type) 변수의 초기화
      // ...
    }

    * 초기화 블럭(initialization block)
      ╰보다 `복잡한{}` 초기화에 사용
  
        클래스 초기화 블럭 - 클래스 변수의 복잡한 초기화에 사용
        인스턴스 초기화 블럭 - 인스턴스 변수의 복잡한 초기화에 사용
        
        class InitBlock {
            static { /* 클래스 초기화 블럭임. */ }
            { /* 인스턴스 초기화 블럭임. */ }
            // ...
        }

    * 인스턴스 초기화 블럭
      ╰생성자의 `중복코드 제거`에 사용(잘 안씀)
  
      인스턴스 초기화 블럭 예시
      {
        count++;
        serialNo = count;
      }

* 멤버변수의 초기화 시기와 순서

class InitTest {
    // 명시적 초기화
    static int cv = 1;
    int iv = 1;

    static { cv = 2; }      // 클래스 초기화 블럭
    { iv = 2; }             // 인스턴스 초기화 블럭
    InitTest() { iv = 3; }  // 생성자
}


[ 클래스 초기화 순서 (최초 1회) ]
1. 기본값 ──────────> cv = 0
2. 명시적 초기화 ───> cv = 1
3. 클래스 블럭 ─────> cv = 2

[ 인스턴스 초기화 (객체 생성마다) ]
4. 기본값 ──────────> iv = 0
5. 명시적 초기화 ───> iv = 1
6. 인스턴스 블럭 ───> iv = 2
7. 생성자 ──────────> iv = 3
