* 상수와 리터럴
  변수(variable) - 하나의 값을 저장하기 위한 공간
  상수(constant) - 값을 한번만 저장할 수 있는 공간
  리터럴(literal) - 그 자체로 값을 의미하는 것

★"모든값에는 타입이 있고, 타입을 모르면 해석할 수 없다."

char('')는 기본형, String("")은 참조형

char ch = 'Java'; 이렇게 할 수 없다.　  불가능✘
String str = ""; 내용이 없는 빈 문자열   가능○
char ch = ''; 에러 ''안에 반드시 하나의 문자가 필요!  불가능✘
char ch = ' '; 공백문자(blank)로 변수 ch를 초기화  가능○


■문자열 결합

'+' 기호는 상황에 따라 하는 일이 다르다
숫자를 더할 때는 덧셈, 집합을 더할 때는 합집합

7 + " " → "7" + " " → "7 "
" " + 7  → " " + "7" → " 7"
7 + "7"  →  "7" + "7" → "77"

7 + 7 + "" → 14 + "" → "14" + "" → "14"
"" + 7 + 7 → "7" + 7 → "7" + "7" → "77"
