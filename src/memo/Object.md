* 객체지향언어
- 기존 프로그래밍 언어에 「객체지향개념(규칙)」을 추가

★장점
1. 코드의 `재사용성`(*상속)이 높다.
　　→ 새로운 코드를 작성할 때 기존의 코드를 이용하여 쉽게 작성할 수 있다.
2. 코드의 관리가 용이하다.
　　→ 코드간의 관계를 이용해서 적은 노력으로 쉽게 코드를 변경할 수 있다.
3. 신뢰성이 높은 프로그래밍을 가능하게 한다.
　　→ 제어자와 메서드를 이용해서 `데이터를 보호`(*캡슐화)하고 올바른 값을 유지하도록 하며, `코드의 중복을 제거`하여 코드의 불일치로 인한 오동작을 방지할 수 있다.

- oop(객체지향 프로그래밍)개념
  ①캡슐화 - 데이터를 보호.
  ②상속 - 코드를 재사용.
  ③추상화 - 공통점을 뽑아냄.
  ④다형성 - 하나의 참조변수로 여러객체를 다루게 함.

- 클래스(서로관련된 집합, 묶음, 그룹)와 객체
  클래스의 정의 - 클래스란 객체를 정의해 놓은 것.
  클래스의 용도 - 클래스는 객체를 생성하는데 사용.

객체의 정의 - 실제로 존재하는 것. 사물 또는 개념.
객체의 용도 - 객체가 가지고 있는 기능과 속성에 따라 다름.

- 클래스(제품의 설계도) →(인스턴스화) 객체(제품)
  TV설계도 / TV
  붕어빵틀 / 붕어빵

- 객체의 구성요소 - 속성(변수)과 기능(메서드)
  속성 : 크기, 길이, 높이, 색상, 볼륨, 채널 등
  기능 : 켜기, 끄기, 볼륨 높이기, 볼륨 낮추기, 채널 변경하기 등

속성(property) → 멤버변수(member variable)
기능(function) → 메서드(method)

채널(속성, 변수) → int channel
채널 높이기(기능, 메서드) → channelUp() { ... }

- 객체의 생성과 사용 - 변수와 메서드의 사용
  클래스명 변수명;           // 클래스의 객체를 참조하기 위한 참조 변수(리모콘)를 선언
  변수명 = new 클래스명();   // 클래스의 객체를 생성 후, 객체의 주소를 참조 변수에 저장(연결)

// 1. 객체 생성
Tv t;
t = new Tv();

// 2. 객체 사용
t.channel = 7;      // 변수
t.channelDown();    // 메서드

- 객체의 생성과 사용 - 참조의 변경
하나의 인스턴스를 여러 개의 참조 변수가 가리키는 경우(가능)
여러 인스턴스를 하나의 참조 변수가 가리키는 경우(불가능)
