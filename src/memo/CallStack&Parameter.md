class CallStackEx {
    public static void main(String[] args) {
        firstMethod();
    }
    static void firstMethod() {
        secondMethod();
    }
    static void secondMethod() {
        System.out.println("secondMethod()");
    }
}

- 기본형 매개변수와 참조형 매개변수
  기본형 매개변수 : 변수의 값을 읽기만 할 수 있다.(read only)
  참조형 매개변수 : 변수의 값을 읽고 변경할 수 있다.(read & write)

  1. 기본형 매개변수 처리 흐름
  → 기본형은 '값(데이터)자체'가 복사되어 전달되기 때문에, 메서드 안에서 아무리 값을 바꿔도 원본은 안전하다.  

   [단계 1] main에서 객체 생성 및 값 초기화 (d.x = 10)

   [ Call Stack (메모리) ]                [ Heap (메모리) ]
   ┌─────────────────────────┐
   │ main() 방                │
   │  └── d (객체 참조)        │ ───┐
   └─────────────────────────┘    │
   ▼
   ┌──────────────┐
   │ Data 객체     │
   │  └── x = 10  │ <── (원본 x값)
   └──────────────┘
   
   [단계 2] change(d.x) 호출 (값 10만 복사해서 전달)

   [ Call Stack (메모리) ]
  ┌─────────────────────────┐
  │ change(int x) 방        │
  │  └── x = 10             │ <-- main의 d.x 값 '10'이 '복사'되어 들어옴
  ├─────────────────────────┤
  │ main() 방               │
  │  └── d.x = 10           │ <-- 원본 변수는 그대로 가만히 있음
  └─────────────────────────┘

  [단계 3] change 내부에서 x = 1000으로 변경

  [ Call Stack (메모리) ]
  ┌─────────────────────────┐
  │ change(int x) 방        │
  │  └── x = 1000           │ <-- 복사본 방의 x만 1000으로 바뀜! (끝나면 소멸)
  ├─────────────────────────┤
  │ main() 방               │
  │  └── d.x = 10           │ <-- 원본 변수는 여전히 10 유지 (영향 없음)
  └─────────────────────────┘

   ● 결과: change가 끝나고 돌아와도 main의 d.x는 여전히 10입니다.


  2. 참조형 매개변수 (ReferenceParamEx) 처리 흐름
  → 참조형은 '객체의 메모리 주소(참조값)'가 복사되어 전달되기 때문에, 두 변수가 `동일한 Heap객체`를 바라보게 된다.

   [단계 1] main에서 객체 생성 및 값 초기화 (d.x = 10)

  [ Call Stack (메모리) ]                [ Heap (메모리) ]
  ┌─────────────────────────┐
  │ main() 방               │
  │  └── d (주소: 0x100)    │ ───┐ (0x100 주소를 가리킴)
  └─────────────────────────┘    │
  ▼
  ┌─────────────────────┐
  │ Data2 객체 (0x100)  │
  │  └── x = 10         │
  └─────────────────────┘

   [단계 2] change(d) 호출 (주소값 0x100이 복사되어 전달)

   [ Call Stack (메모리) ]                [ Heap (메모리) ]
   ┌─────────────────────────┐
   │ change(Data2 d) 방      │
   │  └── d (주소: 0x100)    │ ──┐
   ├─────────────────────────┘   │
   │ main() 방                   │   (두 변수 모두 똑같은
   │  └── d (주소: 0x100)    │ ──┼─> [ Data2 객체 (0x100) ]
   └─────────────────────────┘   │    └── x = 10
   │
   └── 주소값이 복사되어 같은 객체를 공유함!

   [단계 3] change 내부에서 d.x = 1000 변경

   [ Call Stack (메모리) ]                [ Heap (메모리) ]
   ┌─────────────────────────┐
   │ change(Data2 d) 방      │
   │  └── d (주소: 0x100)    │ ──┐
   ├─────────────────────────┘   │
   │ main() 방                   │   (공유하고 있는 Heap 객체의
   │  └── d (주소: 0x100)    │ ──┼─> [ Data2 객체 (0x100) ]
   └─────────────────────────┘   │    └── x = 10 ➔ 1000 (값 변경!)
                                 │
   ● change 방 안의 d가 가리키는 주소로 찾아가서 객체 내부의 x값을 1000으로 바꿔버린다.
   ● 이 객체는 main도 똑같이 바라보고 있는 객체이다.

   [단계 4] main으로 복귀 후 출력

   [ Call Stack (메모리) ]                [ Heap (메모리) ]
   ┌─────────────────────────┐
   │ main() 방               │
   │  └── d (주소: 0x100)    │ ───┐
   └─────────────────────────┘    │
   ▼
   ┌─────────────────────┐
   │ Data2 객체 (0x100)  │
   │  └── x = 1000       │ <-- 바뀐 값이 그대로 남아있음!
   └─────────────────────┘

   ● 결과: main으로 돌아와서 d.x를 찍어보면, 이미 객체 안의 값이 통째로 바뀌어 있으므로 1000이 출력됩니다.


  💡최종 핵심 요약
  ● 기본형: 값만 복사해서 주므로, 내 방(change)에서 뭘 하든 남의 방(main)은 평화로움(값 유지)
  ● 참조형: 값은 물건(객체)을 가리키는 주소표를 복사해서 주므로, 둘이 같은 물건을 공유해서 조작함(값 변경)
